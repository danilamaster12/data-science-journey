# Анализ оттока клиентов автосервиса (Churn Prediction)

## О чем этот проект?
Это мой первый учебный проект по анализу данных. Я создал искусственную базу данных клиентов автосервиса (100 человек) и проанализировал, кто из них уходит (churn), а кто остается.

## Какие данные использовались?
* `car_year` — год выпуска машины клиента.
* `visits` — сколько раз клиент приезжал на техобслуживание.
* `avg_check` — средний чек за ремонт.
* `churn` — ушел клиент (1) или остался (0).

## Основные выводы:
1. Процент оттока в сгенерированной базе составил около 6%.
2. Интересный факт: у ушедших клиентов средний чек **выше**, чем у оставшихся. То есть сервис теряет не бедных, а более платежеспособных клиентов.
3. Визуализация оттока показывает, что подавляющее большинство клиентов (около 94%) остаются лояльными.

## Инструменты:
* Python (Pandas, Seaborn, Matplotlib)
## Новые инсайты (после добавления типа машины):
* Сервис теряет около **688 964 рублей** из-за ушедших клиентов.
* Самый высокий отток наблюдается среди владельцев **хэтчбеков (65%)**.
* Самые лояльные клиенты — владельцы **внедорожников (SUV)** (отток всего 35%).

## Визуализация
В проекте построены графики:
1. Общий отток клиентов (столбчатая диаграмма).
2. Зависимость оттока от типа автомобиля.
